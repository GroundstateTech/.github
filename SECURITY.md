# Groundstate Security Policy

Always read the target repository's `SECURITY.md`.

Avoid public disclosure of vulnerabilities involving authentication bypass, credentials, private keys, personal/medical/employee/financial data, source-identifying information, sensitive operational data, remote-code execution, or unsafe file handling.

Groundstate contains research prototypes and development software. A public repository does not imply a professional security audit or production suitability.

Do not describe Groundstate software as anonymous, untraceable, end-to-end encrypted, clinically secure, hardened, certified, or production-safe unless that claim is expressly documented and supported for that specific release.
