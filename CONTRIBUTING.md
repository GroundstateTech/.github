# Groundstate Contribution Guidelines

Read the target repository's README, license, contributing guide, and security policy before submitting work.

Keep changes scoped, explain the problem being solved, and add or update tests where behavior changes. Do not submit third-party code, data, media, documentation, or proprietary specifications unless you have the right to do so.

Contributors retain copyright in their contributions unless a separate written assignment applies. A contribution does not create employment, partnership, equity, membership interests, ownership of Groundstate Technology LLC, or rights in unrelated Groundstate intellectual property.

Do not submit credentials, API keys, private keys, patient information, payroll data, private operational datasets, or other sensitive information in issues or pull requests.

For research-oriented projects, preserve source/provenance information, distinguish observations from interpretation, disclose important assumptions, avoid overstating certainty, and do not fabricate test data or results.
